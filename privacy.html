Privacy Policy

Last updated: November 11, 2026

tiktoklive ("the app") is a personal tool that uploads the operator's own video clips to the operator's own TikTok account as drafts.

Data we access

  • Basic TikTok profile information of the operator's account (open ID, display name, avatar), through the user.info.basic scope, only to confirm which account is connected.
  • Permission to upload videos to that account's drafts, through the video.upload scope.

How data is stored

Access tokens are stored only on the operator's own computer and are never shared, sold or sent to any third party. The app has no user accounts, no analytics and no advertising.

Data deletion

The operator can revoke access at any time in the TikTok app (Settings and privacy → Security → Manage app permissions) and delete the locally stored tokens.

Contact

Questions can be raised through this site's GitHub issues page.
